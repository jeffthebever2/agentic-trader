# DESIGN.md — TradingAgents Dashboard

> Generated by impeccable `document`. Register: **product** (design serves a
> task-focused trading tool). Single-file app: `web/static/index.html`.
> Authoritative overrides live in `<style id="ta-redesign">` (loads last).

## Register & Scene

Product register. Scene sentence: *a retail trader at a desk on a 24–27"
monitor in daytime ambient light, scanning live positions and model verdicts
under mild time pressure.* → **light theme, single mode** (no dark mode; the
scene does not force one). The tool disappears into the task; familiarity is a
feature, not a flaw.

## Color (Restrained strategy, warm-tinted neutrals)

Accent is genuinely warm orange-red, so every neutral is tinted warm — this is
cohesion with *this* brand, not the lazy warm-default.

| Token | Value | Role |
|---|---|---|
| `--canvas` | `#F5F4F1` | App background (warm paper, not flat slate) |
| `--surface` | `#FCFBFA` | Sidebar / chrome — second neutral layer |
| `--surface-soft` | `#F2F1ED` | Recessed fills, scrollbar track |
| `--surface-raised` | `#EBE9E4` | Hover fills |
| `--surface-rule` | `#E2DFD8` | Warm hairline borders |
| `--ink` | `#1A1714` | Primary text (warm near-black, never `#000`) |
| `--ink-muted` | `#534E47` | Secondary text (~8:1 on white) |
| `--ink-faint` | `#736C61` | Meta/labels (~4.7:1 — WCAG AA) |
| `--accent` | `#D63A00` | Primary actions, selection, state ONLY — not decoration |
| `--accent-subtle` | `rgba(214,58,0,.09)` | Active nav / selected row wash |

Semantic: green = buy/long, red = sell/short, amber = hold (pre-existing,
kept). 60-30-10 by weight: canvas/surfaces 60, ink/borders 30, accent ≤10.

## Typography

- **Sans:** Geist (`--font-sans`), one family, weights 400–800.
- **Mono:** JetBrains Mono (`--font-mono`) — all numerics, tickers, code, kbd.
  Applied globally via `[style*="monospace"]` remap.
- Body `font-size: .875rem` (rem, not px — respects user zoom). `tabular-nums`
  + `font-kerning: normal` global; `font-variant-ligatures: none` on code.
- Product scale: tight ratio. Page H1 `18px/700/-0.02em`. Body 13–14px.
  No fluid `clamp()` in product UI (spatial predictability).
- All-caps eyebrows/labels: `letter-spacing: .11em`. `text-wrap: balance` on
  headings, `pretty` + `72ch` max on report prose.

## Layout

- Familiar shell: 236px left sidebar (second neutral layer) + 60px header +
  scrollable `<main>`. Predictable grid; consistency is the affordance.
- Cards only where elevation communicates hierarchy: `#FFF`, 10px radius,
  warm hairline, tinted diffusion shadow, hover-lift. No nested cards.
- No side-stripe accent borders anywhere (absolute ban) — full borders +
  tinted wash for verdict/message states.

## Motion (emil-design-eng)

- Tokens: `--ease-out: cubic-bezier(.23,1,.32,1)`,
  `--ease-in-out: cubic-bezier(.77,0,.175,1)`. No `linear`/`ease-in` on UI.
- 120–200ms, property-specific (never `transition: all`). State only — no
  page-load orchestration.
- Press feedback `scale(.97)` on every button. Perpetual motion only for
  live-status indication. `prefers-reduced-motion` honored globally.

## State Vocabulary

Every interactive element ships: default, hover, focus-visible (2px accent
ring), active (press), disabled (.55 opacity, no transform). Skeleton loaders
(`.skeleton` shimmer) over spinners. Keep existing empty/error states.

## Absolute Bans (enforced)

No Inter, no `#000`/`#fff` flat, no neon/outer-glow shadows, no gradient text,
no side-stripe borders, no `transition: all`, no AI-purple, no `px` body type,
no `user-scalable=no`, no decorative motion.

## When Editing

Change tokens in `:root` of `#ta-redesign`, not scattered inline styles.
Structural chrome uses inline `style=""` (high specificity) — override there
with `!important` and a comment citing the rule. Never break trading
functionality; CSS-only changes preferred.
