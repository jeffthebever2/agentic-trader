# Thematic Engine v2 — TRUE FULL REVAMP: "More Data, More Sources"

## 1. Verdict — what "true v2 of the whole engine" means here

The current engine advertises 19 sources but runs ~11, and the two structurally best ideas (`discovery` breakout, `analyst` confirmation) are OFF — analyst because it's O(universe × 4 sequential calls) and times out every scan; discovery because a flag is false. Meanwhile **two already-configured keys (FMP, FINNHUB) are tapped at ~10% of their surface**, XAI is *blank* (the brief's "Grok configured" claim is wrong — verified `.env` line 23), and a dozen keyless structured feeds (SEC EDGAR, StockTwits, Wikipedia pageviews, GDELT, exchange halts, CBOE options) are unused. Worse, the learning loop **has never produced a single weight in production** (34 orphan rows, 0 forward returns filled, no weights file on disk) and its attribution is polluted by non-source keys (`bull_bear_ratio=999` soaks ~90% of credit).

**v2 is not "add scrapers." It is a structural inversion:** (a) replace fragile HTML scrapes with the structured keyed/keyless JSON that says the *same thing more reliably*; (b) move all fundamental/analyst/social-sentiment data from blind **pre-merge universe scans** to a single **post-merge enrichment dossier over the top ~20–40 ranked names**, behind a shared per-ticker daily-TTL cache; (c) **tag every source with a modality** (social / news / smart-money / price-momentum / analyst / options / insider / attention / regime) so the confirmation bonus rewards *orthogonal* agreement, not six news-RSS feeds echoing one event; (d) **use that one dossier three times** — ground the `_ai_pick` prompt, feed the position sizer, and drive data-aware exits — where today all three are blind to data the engine already fetches and throws away; (e) **fix the learning loop** (whitelist real source keys, market-relative magnitude-aware returns, a backfill job, regression attribution) so weights finally move. Compliance kill-chain, HIL propose-only, and the just-shipped v2 diversification stay untouched.
